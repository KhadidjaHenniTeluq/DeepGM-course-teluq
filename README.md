# Modèles génératifs profonds

Site du cours **Modèles génératifs profonds** — Khadidja Henni, TÉLUQ.

Le cours se déroule sur 15 semaines. Chaque semaine comprend une vidéo d'introduction, un support PDF à télécharger, un laboratoire et un quiz. Sept évaluations (mini-projets) et un projet final complètent le parcours.

## Structure

```
content/            pages du cours (semaines, laboratoires, évaluations, projet final)
data/quiz/          questions des quiz
static/pdf/         supports PDF
static/videos/      vidéos d'introduction
layouts/            gabarits du site
themes/hugo-book/   thème
outils/animations/  sources des vidéos
```
